list 命令 ​

list 命令用于列出各种类型的资源，支持分页、排序、筛选等功能。

命令语法 ​

bash
platformctl <CLUSTER> <RESOURCE_TYPE> list [OPTIONS]

其中 <CLUSTER> 是集群名称，可以通过 tui 命令查看可用的集群列表。

支持的资源类型 ​

  • job-pack - 训练任务
  • workstation - 开发机
  • inference - 推理服务
  • job-data - 数据处理
  • volume - 个人卷
  • storage-pool - 存储池
  • jobqueue - 任务队列

通用参数 ​

分页参数 ​

  • --offset <NUMBER>: 分页偏移量（默认：0）
  • --limit <NUMBER>: 每页显示数量（默认：20）

排序参数 ​

  • --order-by <FIELD>: 排序字段，可选值：
    • create_time - 创建时间（默认）
    • update_time - 更新时间
    • name - 名称
  • --reverse: 反向排序

搜索参数 ​

  • --query <TEXT>: 搜索查询文本

通用输出示例 ​

┌─────────────────┬──────────┬─────────────┬──────────────┬─────────────┬─────────────┐
│ 显示名称        │ 状态     │ 运行时间    │ 名称         │ 创建人      │ 工作队列    │
├─────────────────┼──────────┼─────────────┼──────────────┼─────────────┼─────────────┤
│ 我的训练任务    │ 运行中   │ 2h30m15s    │ my-job-001   │ 张三        │ gpu-queue   │
│ 测试任务        │ 成功     │ 1h15m30s    │ test-job-002 │ 李四        │ cpu-queue   │
└─────────────────┴──────────┴─────────────┴──────────────┴─────────────┴─────────────┘

资源特定参数 ​

训练任务 (job-pack) ​

bash
platformctl <CLUSTER> job-pack list [OPTIONS]

特定参数 ​

  • --phase <PHASE>: 按阶段筛选，可选值：
    • pending - 等待中
    • running - 运行中
    • succeeded - 成功
    • failed - 失败
    • cancelled - 已取消
  • --owner <USER>: 按创建人筛选
  • --jobqueue <QUEUE>: 按工作队列筛选

使用示例 ​

bash
# 列出所有训练任务
platformctl <CLUSTER> job-pack list

# 列出运行中的训练任务
platformctl <CLUSTER> job-pack list --phase running

# 按创建人筛选
platformctl <CLUSTER> job-pack list --owner 张三

# 分页显示
platformctl <CLUSTER> job-pack list --offset 20 --limit 10

# JSON 格式输出
platformctl <CLUSTER> job-pack list --output json --pretty-print

开发机 (workstation) ​

bash
platformctl <CLUSTER> workstation list [OPTIONS]

特定参数 ​

  • --phase <PHASE>: 按阶段筛选，可选值：
    • pending - 等待中
    • running - 运行中
    • stopped - 已停止
    • failed - 失败
  • --owner <USER>: 按创建人筛选
  • --jobqueue <QUEUE>: 按工作队列筛选

推理服务 (inference) ​

bash
platformctl <CLUSTER> inference list [OPTIONS]

特定参数 ​

  • --owner <USER>: 按创建人筛选
  • --jobqueue <QUEUE>: 按工作队列筛选

数据处理 (job-data) ​

bash
platformctl <CLUSTER> job-data list [OPTIONS]

特定参数 ​

  • --owner <USER>: 按创建人筛选
  • --jobqueue <QUEUE>: 按工作队列筛选

个人卷 (volume) ​

bash
platformctl <CLUSTER> volume list [OPTIONS]

特定参数 ​

  • --read-write <USER>: 按读写用户筛选
  • --read-only <USER>: 按只读用户筛选

存储池 (storage-pool) ​

bash
platformctl <CLUSTER> storage-pool list [OPTIONS]

特定参数 ​

  • --phase <PHASE>: 按阶段筛选，可选值：
    • active - 活跃
    • inactive - 非活跃
    • maintenance - 维护中
    • failed - 失败
  • --maintainer <USER>: 按管理员筛选

任务队列 (jobqueue) ​

bash
platformctl <CLUSTER> jobqueue list [OPTIONS]

特定参数 ​

  • --phases <PHASE>: 按阶段筛选，可选值：
    • active - 活跃
    • inactive - 非活跃
    • maintenance - 维护中
  • --maintainers <USER>: 按管理员筛选

使用技巧 ​

1. 组合筛选 ​

bash
# 组合多个筛选条件
platformctl <CLUSTER> job-pack list --phase running --owner 张三 --jobqueue gpu-queue

2. 排序和分页 ​

bash
# 按创建时间倒序排列，显示前10条
platformctl <CLUSTER> workstation list --order-by create_time --reverse --limit 10

3. 搜索功能 ​

bash
# 搜索包含特定关键词的资源
platformctl <CLUSTER> job-pack list --query "pytorch"

4. 输出格式 ​

bash
# JSON 格式输出，便于程序处理
platformctl <CLUSTER> job-pack list --output json --pretty-print

# YAML 格式输出
platformctl <CLUSTER> workstation list --output yaml

常见问题 ​

Q: 如何查看所有可用的筛选条件？ ​

A: 使用 platformctl <RESOURCE_TYPE> list --help 查看特定资源类型的所有参数。

Q: 如何导出列表数据？ ​

A: 使用 --output json 或 --output yaml 参数，然后重定向到文件。

Q: 可以同时使用多个筛选条件吗？ ​

A: 可以，多个筛选条件会同时生效，相当于 AND 操作。

Q: 如何查看资源的详细信息？ ​

A: 使用 get 命令查看特定资源的详细信息。
