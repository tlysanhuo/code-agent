list 命令
​
list
命令用于列出各种类型的资源，支持分页、排序、筛选等功能。
命令语法
​
bash
platformctl
<
CLUSTE
R
>
<
RESOURCE_TYP
E
>
list
[OPTIONS]
其中
<CLUSTER>
是集群名称，可以通过
tui
命令查看可用的集群列表。
支持的资源类型
​
job-pack
- 训练任务
workstation
- 开发机
inference
- 推理服务
job-data
- 数据处理
volume
- 个人卷
storage-pool
- 存储池
jobqueue
- 任务队列
通用参数
​
分页参数
​
--offset <NUMBER>
: 分页偏移量（默认：0）
--limit <NUMBER>
: 每页显示数量（默认：20）
排序参数
​
--order-by <FIELD>
: 排序字段，可选值：
create_time
- 创建时间（默认）
update_time
- 更新时间
name
- 名称
--reverse
: 反向排序
搜索参数
​
--query <TEXT>
: 搜索查询文本

​
┌─────────────────┬──────────┬─────────────┬──────────────┬─────────────┬─────────────┐

└─────────────────┴──────────┴─────────────┴──────────────┴─────────────┴─────────────┘

​

: 按阶段筛选，可选值：

- 等待中

- 运行中

- 成功

- 失败

- 已取消

: 按创建人筛选
--jobqueue <QUEUE>
: 按工作队列筛选

常见问题
​
Q: 如何查看所有可用的筛选条件？
​
A: 使用
platformctl <RESOURCE_TYPE> list --help
查看特定资源类型的所有参数。
Q: 如何导出列表数据？
​
A: 使用
--output json
或
--output yaml
参数，然后重定向到文件。
Q: 可以同时使用多个筛选条件吗？
​
A: 可以，多个筛选条件会同时生效，相当于 AND 操作。
Q: 如何查看资源的详细信息？
​
A: 使用
get
命令查看特定资源的详细信息。
