队列 ​

队列划分一组机器给一组用户使用，工作队列负责资源使用的汇总和调度。由于集群内卡资源紧张，所以会有多个队列共享 GPU 情况。

队列的作用 ​

  • 资源隔离：确保不同用户或团队间的资源得到有效隔离，按需分配，防止资源竞争。
  • 负载均衡：有助于平衡集群负载，同时保障资源不被未授权访问，确保整个集群的安全性。

队列分类 ​

在集群中，资源通过多个队列进行分类与管理，分为以下两种类型：
公共队列：配置为集群用户或拥有集群个人卷的用户共享使用。
专属队列：仅该队列用户列表中的用户可见和可用，其他用户无法使用该队列资源。

队列使用权限 ​

  • 集群管理员:
    • 可以创建和更新、删除队列。
    • 可以指派和管理队列管理员。
  • 队列管理员:
    • 可以更新队列的用户列表和配置。
    • 可以进行资源的转让和分配。
    • 在创建任务时，支持手动指定节点。
  • 集群用户:
    • 可以使用公共队列中的资源。
    • 需要获得相应权限后才能使用专属队列的资源。
    • 所有用户均有权查看其权限范围内的队列使用详情，以便于资源使用的协调。

基本操作 ​

管理队列节点

  • 添加/移除节点：在队列列表页面，找到相应队列，点击【更新】按钮，在弹出的编辑页面中调整队列信息，实现节点的添加或删除。
  • 封锁节点：节点可进行自我检查并自动封锁，管理员亦可手动选择节点进行封锁。
  • 节点迁移：管理员可以根据需要，将节点在队列之间进行迁移。

用量详情查看 ​

在创建工作负载前，用户可通过用量详情功能确认队列的可用资源情况。点击队列列表中的用量详情按钮即可查看。

GPU 节点 ​

点击右上角的 GPU 节点 选项卡，即可查看 GPU 资源的占用与可用情况（展示效果如下图）：

  • GPU 节点分类：平台将 GPU 节点按占用情况分为两类
    • 独占节点：GPU 卡数 ≥ 8 张的节点，资源独立占用，不与其他任务共享。
    • 非独占节点：GPU 卡数 < 8 张的节点，资源可被多个小任务共享使用。
  • 资源查询指引
    • 若需运行整节点任务（总 GPU 数为 8 的整数倍），请以空闲节点数量为准，此类节点可直接分配完整资源。
    • 若需运行小规格任务（总 GPU 数 ＜ 8 张），可综合查看空闲节点剩余卡数和非独占节点剩余卡数，两者之和为可用的总卡数。

非独占节点展示讲解 ​

非独占节点区域将以更精细的维度展示节点内 GPU 卡的占用分布。

  • 以图示为例：当前非独占节点集群共包含 2 个物理节点（总计 16 张 GPU 卡），其中已被占用的 GPU 卡数为 11 张。
  • 在列表中选中某一用户的占用数据时，系统会自动将该用户的占用记录置顶，直观的展示其具体占用的节点及对应 GPU 卡信息。

CPU 节点 ​

点击右上角的 CPU 节点 选项卡，即可查看 CPU 资源的实时状态（展示效果如下图）：

  • 顶部汇总区：展示当前所有 CPU 节点的总可用核心数与总可用内存量，帮助快速判断资源整体余量。
  • 下方详情列表：按用户维度拆分展示各用户已占用的核心数明细。
